# ArogyamCare

**ArogyamCare** is a health-focused app designed to help users find doctors, book appointments, and access local pharmacies. The app aims to streamline healthcare access, particularly in times of emergencies, offering a user-friendly platform for connecting patients with medical professionals and resources.

## Features

- **Doctor Search**: Users can find doctors in their local area, check their availability, and book appointments directly through the app.
- **Pharmacy Finder**: Locate nearby pharmacies where prescribed medications can be picked up.
- **Appointment Booking**: Secure and simple appointment scheduling with medical professionals.
- **Blood Bank Services (Upcoming)**: Check blood availability by group in nearby blood banks, with options for online booking.
- **Medicine Ordering (Upcoming)**: Order medicines that are not available locally and get them delivered.

## Upcoming Features

- **Blood Availability Checking and Booking**: Users can book blood from a blood bank based on availability and pick it up when needed.
- **Online Medicine Ordering**: Users will be able to order medicines from within the app if they are unavailable in the local area.
- **Symptoms Checker**: The app will allow users to search for possible conditions based on their symptoms.
- **Emergency Contact**: Connect with healthcare providers during emergencies.

## How it Works

1. **Search for Doctors**: Users can easily find doctors based on their specialty and location.
2. **Book Appointments**: Schedule appointments directly with doctors.
3. **Pharmacy Details**: Find out which pharmacy has the medicines prescribed by your doctor.
4. **Check Blood Availability** (Upcoming): Find and book blood based on your requirements.
5. **Order Medicines** (Upcoming): Conveniently order essential medicines that are hard to find locally.

## Tech Stack

- **Frontend**: React Native for cross-platform mobile application development.
- **Backend**: Node.js and PHP for handling server-side operations.
- **Database**: MySQL for secure data storage.
- **Camera Feature**: Python-based camera integration for future medical symptoms detection functionality.

## Installation

### Prerequisites

- Node.js
- MySQL
- Python (for future camera features)
- React Native development environment

### Steps to Install

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/arogyamcare.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your environment variables for the backend (database credentials, etc.).
4. Run the backend server:
   ```bash
   npm run server
   ```
5. Run the React Native app:
   ```bash
   npx react-native run-android
   ```
